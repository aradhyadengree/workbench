# Code of Conduct

Workbench follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep criticism about the work rather
than the person. Harassment, discriminatory language, and personal attacks aren't tolerated in
issues, pull requests, or any other project space.

To report a problem, contact the maintainers privately through
[GitHub Security Advisories](https://github.com/aradhyadengree/workbench/security/advisories/new)
(choose "Report a vulnerability" and mark the report as a conduct issue). Reports are kept confidential.
